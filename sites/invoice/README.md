# invoice — free German invoice generator with e-invoice output

A free, fully client-side invoice generator for German freelancers and small businesses
("Rechnung schreiben"). Produces a polished PDF that is simultaneously a valid
**e-invoice**: PDF/A-3 with embedded Factur-X/ZUGFeRD XML (EN 16931 profile).

**Nothing leaves the browser.** No server, no account, no cookies. Sender profile, saved
clients, and drafts live in `localStorage`, with JSON export/import for backup.

## Develop

```bash
npm ci
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build → dist/
npm run preview
```

Node ≥ 22. Run all commands inside this folder (monorepo rule — no root package.json).

## Stack

Vite + React + TypeScript, plain CSS. PDF authoring and PDF/A-3/Factur-X conversion via
[`@cantoo/pdf-lib`](https://www.npmjs.com/package/@cantoo/pdf-lib) (MIT, maintained
pdf-lib fork) with `@pdf-lib/fontkit` for font embedding. The EN 16931 CII XML is
generated by a hand-written, dependency-free serializer in `src/cii/`.

## Deployment

Cloudflare Pages via `.github/workflows/invoice.yml` (build in Actions, Direct Upload;
see `sites/conflicts/docs/hosting-architecture.md` for the umbrella model). Planned
hostname: `invoice.teespoon.io`.
